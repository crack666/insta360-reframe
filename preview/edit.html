1 · Blickrichtung

Klick = Preset ansehen. Ziehen im Bild = freier Blick. C = Cut Preset · X = Cut custom (aktueller Blick, grau).

U = aktuelles Segment überschreiben (Blick + Lens), ohne neuen Cut.

Default = FOV aus Preset/Custom. Linear/Ultra überschreiben nur den Zoom für das Segment — Richtung bleibt.

Take-Mount-Offset (alle Presets gleich drehen)

Optional: dreht alle named Presets um denselben Winkel (Mount). Einzelnes Preset (z.B. nur Selfie) → unten „Nur für diesen Take“.

Kein Take-Kontext — Offset nur mit Projekt/Take.

Named Presets kalibrieren

Kein Take — nur globales Speichern möglich.

2 · Vorschläge (semi-auto)

Wann ein Vorschlag entsteht (Schieberegler = Trigger): Ruhe = Bildbewegung länger als „Min. Ruhe-Dauer“ unter dem Ruhe-Schwellwert (Strenge ↑ = strenger). Selfie-Check = alle paar Sekunden wird dein gespeichertes Selfie-Preset als Flat-Frame gerendert; wenn hautfarbene Pixel ≥ „Min. Hautanteil“ → Vorschlag (kein echter Gesichtserkenner). Spike = plötzliche Bewegung (nur Marker). Badge „X% sicher“ = Confidence, nicht Hautanteil.
